## 📖 このプロジェクトについて（初めての方へ）

### 簡単に言うと？

本リポジトリは、**阪上循環方程式群** という数学的構造を提案・検証する公開研究プロジェクトです。以下の特徴があります：

- **数学的厳密性**: コンピュータで検証可能な形で実装
- **完全透明性**: すべてのコード、テスト、失敗事例が公開
- **反証の記録**: 理論と異なる観測値も永遠に保存
- **再現性**: 誰でも同じ環境でテストを再現可能

### 何をしているのか？

| 項目 | 状態 | 詳細 |
|:---|:---:|:---|
| 数学的一貫性 | ✅ | 実装コードが自分自身と矛盾なく動く |
| 物理的意味 | ❌ | 現実世界の物理法則として検証されていない |
| 第三者確認 | ❌ | 独立した研究者による再現がまだ |
| 科学誌投稿 | ❌ | ピアレビュー済みの発表はなし |

**重要**: ✅ = 「プログラム内部で一貫している」という意味です。❌ = 「自然界の法則として証明された」ではありません。

## 🔬 主要な研究成果

### 阪上循環方程式群 Major 8

8つの相互関連した数学的式から構成されています：

| 式 | 名称 | 何をするか |
|:---:|:---|:---|
| 第1式 | 偏差0量子整合式 | 最小値の自動補正 |
| 第2式 | ラグランジアン潜伏干渉式 | 微小な振動の重ね合わせ |
| 第3式 | 群層流接続式 | 黄金比による減衰 |
| 第4式 | フィボナッチ行列式 | 数列と行列の対応 |
| 第5式 | 位相安定式 | 角度の安定性確認 |
| 第6式 | 時間反転対称性 | 時間を逆にしても同じ |
| 第7式 | 位相テンソルノルム | 多次元構造の大きさ |
| 第8式 | 全環循環統括式 | すべてを統括する循環度 |

### 現在の検証状況

**✅ 確認済み**:
- Fibonacci数列の再帰（フィボナッチ数列の性質）
- 阪上行列の数学的性質（対称性・階数）
- 時間反転対称性（100%合致）
- 数値計算の一貫性

**⚠️ 未確認項目**:

- **物理的解釈**: これらの方程式が現実の物理現象を説明するかどうか
- **スケーラビリティ**: より大きな問題でも動くかどうか

## 🛠️ インストール・実行方法

### 1. 必要なもの

- Python 3.10以上
- NumPy, SciPy ライブラリ

```bash
pip install numpy scipy
```

### 2. リポジトリをダウンロード

```bash
git clone https://github.com/tetsushisakagami-svg/sakagami-circulation-equations.git
cd sakagami-circulation-equations
```

### 3. テストを実行

```bash
python sakagami_equations.py
```

実行後、`sakagami_validation_output/` ディレクトリに詳細なレポート（JSON形式）が生成されます。

## 🔐 検証・透明性のしくみ

### 「信頼できるの？」という質問への答え

本リポジトリは、信頼性を確保するため複数の層を持ちます：

#### 層1: ソースコード公開
- **何が起きているか**: すべてのコードが GitHub 上で読める
- **確認方法**: 自分でダウンロードして実行できる
- **利点**: 「隠れた計算」がない

#### 層2: 完全記録化
- **何が起きているか**: テストの全過程がファイルに保存される
- **確認方法**: JSON ファイルを見れば再現可能
- **利点**: 「後から変えられた」ことがない

#### 層3: 反証の永遠保存
- **何が起きているか**: うまくいかなかった結果も保存
- **確認方法**: `UNRESOLVED_NOT_REPRODUCED` の記録を見る
- **利点**: 「都合の悪い結果を隠した」ことがない

#### 層4: SHA-256チェックサム
- **何が起きているか**: ファイルの改ざんを検出
- **確認方法**: チェックサムを計算して比較
- **利点**: 「こっそり書き換えられた」ことを検出可能

## ⚠️ 重要な注意事項

### これは「証明」ですか？

いいえ。これは「一貫性のある数学的実装」です。

- ✅ できていること: 内部的に矛盾なく動く
- ❌ できていないこと: 物理法則として証明される

### 実際に使えますか？

検証中です。一部の計算は信頼できますが、すべての用途に対応するわけではありません。

### なぜ「0.81649658」の値が記録されているのか？

**科学的誠実性**のためです。古いバージョンで観測された値が現在のコードで再現されない場合、その値を「未解決」として永遠に保存しています。これは「隠す」のではなく「記録する」ことで、未来の研究者が同じ問題に取り組む際の手がかりになります。
2026年11月1日、ルート3をルート2で計算してしまった事が発覚。1.0000恒等の検証に成功。💓😊🉑㊗️
